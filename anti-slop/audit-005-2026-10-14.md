# Anti-slop audit 005

Date: 2026-10-14  
Scope: admin Live Listings card metadata  
Mode: after

## Finding

1. **Trailer status is repeated in the live-listing summary** (LOW)

   The Live Listings cards append `Trailer selected` or `No trailer selected` to the compact metadata line even though trailer selection is already handled in the Screen Listing form. This adds a state marker the admin did not ask to see and makes the movie summary harder to scan. It conflicts with R-05 (hierarchy/rhythm), R-16 (copy economy), and C-3 (content-driven composition).

   Proposed fix: remove only the trailer-status token from the admin `renderEntries()` metadata line. Keep trailer lookup, saved trailer IDs/URLs, and public movie-card trailer embeds unchanged.

## Approval gate

Approved finding `1` on 2026-10-14.

## Resolution

Removed only the `Trailer selected` / `No trailer selected` token from the admin `renderEntries()` metadata line. Trailer lookup controls, saved trailer IDs/URLs, and public movie-card trailer embeds remain unchanged.
