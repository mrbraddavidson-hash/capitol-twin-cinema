# Anti-slop audit 006

Date: 2026-10-15  
Scope: admin Live Listings trailer visibility  
Mode: after

## Finding

1. **Saved official trailers are absent from the Live Listings cards** (MEDIUM)

   The live admin cards currently expose the title, screen, schedule, rating/runtime, synopsis, and edit/remove actions, but no trailer preview. The listing data already carries validated YouTube trailer IDs/URLs, and the Screen Listing form still exposes trailer selection. This forces the owner to leave the card or open the public site to confirm the selected trailer.

   Proposed fix: add a compact, poster-style trailer preview to each Live Listings card when a valid saved trailer ID exists. Use the existing YouTube thumbnail source and a click-to-load `youtube-nocookie.com` iframe with `playsinline=1`, `rel=0`, and no autoplay. Keep trailer lookup, stored IDs/URLs, public movie-card embeds, and cards without trailers unchanged.

## Approval gate

Approved finding `1` on 2026-10-22.

## Resolution

Added a compact poster-style preview to Live Listings cards when a saved official YouTube trailer ID is present. Clicking `Play trailer` replaces only that preview with a privacy-enhanced `youtube-nocookie.com` iframe using `playsinline=1`, `rel=0`, and no autoplay. Cards without a valid trailer ID remain unchanged.

- Build: `node --check public/admin/admin.js` and `npm.cmd run build` passed.
- Deployment: Worker version `b1746b92-016a-45bb-afaf-6532d0389741`.
- Production HTTP verification: the admin shell references the new cache-busted JS/CSS, both assets contain the preview implementation, and the live listings retain official trailer IDs for Verity and Heart of the Beast.
- Public site and stored listing data were not changed.
