# Anti-slop audit 003

Date: 2026-10-14
Scope: public movie-card source note
Mode: after

## Finding

1. **Operational source note exposed in public listings** (LOW)

   The live `/api/showtimes` payload currently sends the note `Facebook indexed post lists Thanksgiving weekend times. Confirm by phone.` for both Screen 1 and Screen 2. The public listing renderer displays the `notes` field directly on each movie card, so an internal freshness/verification reminder is visible to visitors as listing copy. It adds operational clutter without helping visitors choose a film, and it is outside the requested movie title, date, showtime, and metadata fields.

   Proposed fix: clear the `notes` value for the two current entries only. Leave titles, dates, showtimes, TMDB metadata, trailers, and poster URLs unchanged. No source-code or layout changes are needed.

## Approval gate

No KV data or deployment was changed by this audit. Approve finding `1` to clear this note from both live movie cards and verify the public API and rendered page.

## Resolution

Finding 1 approved and fixed. The live KV listing data now has empty `notes` values for Screen 1 and Screen 2; titles, dates, showtimes, TMDB metadata, trailers, and poster URLs were preserved. The public `/api/showtimes` response and the rendered page were rechecked after refresh, and the Facebook/phone note no longer appears on either movie card.
