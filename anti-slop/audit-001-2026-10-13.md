# Anti-slop audit 001

Date: 2026-10-13
Scope: current Now Showing data and the requested Facebook movie update
Mode: after

## Evidence checked

- Current public state in the `NOW_SHOWING` KV namespace lists `Forgotten Island` on Screen 2 and `Verity` on Screen 1, both dated `Oct 2–8, 2026`.
- The most recent indexed Capitol Twin Cinema Facebook post available during this audit names `Heart of the Beast` and `Verity` for Thanksgiving weekend and lists showtimes. The direct Facebook page was temporarily blocked, so this is indexed-post evidence rather than a live Page read.
- Latest indexed post: [Happy Thanksgiving](https://www.facebook.com/CapitolTwinCinema/posts/happy-thanksgiving-we-are-open-all-weekendcome-see-a-showshows-for-sat-sun-monhe/1806564440991712/)
- Earlier supporting post: [Happy Friday](https://www.facebook.com/CapitolTwinCinema/posts/happy-friday-come-check-out-a-movie-tonight-turkey-weekend-is-here-heart-of-the-/1805425551105601/)

## Findings

1. **Stale public listings**

   The live listing still presents `Forgotten Island` and an Oct 2–8 `Verity` run, while the latest available Facebook evidence names `Heart of the Beast` and a new Thanksgiving-weekend schedule. Publishing the old state as current risks sending visitors to the wrong films and times. This violates R-17 (data and dates), R-36 (no fabricated or misleading current claims), and C-5 (evidence over claims).

   Proposed fix: update the two existing listing records only after approval, preserving Verity's existing verified TMDB/trailer fields and replacing the stale Screen 2 title with Heart of the Beast. Keep the Facebook-derived dates and times clearly scoped to the indexed post.

2. **Unconfirmed metadata for the new film**

   The Facebook evidence does not establish Heart of the Beast's rating, runtime, synopsis, poster, trailer, or which screen it occupies. Filling those fields from memory or an unverified search would create plausible-looking but unsupported movie data. This violates R-17, R-36, R-38 (real content or honest placeholder), and C-5.

   Proposed fix: publish only the title and the exact showtime evidence for Heart of the Beast, leave unsupported metadata empty or honest, and add a short confirmation note. Do not assign a screen unless the owner confirms it; the minimal current-state option is to keep Verity on Screen 1 and use Screen 2 for the replacement.

3. **Source freshness boundary**

   The direct Facebook Page was temporarily blocked during the check. The checker cannot truthfully label this result as a live scrape or guarantee that the indexed post is still the theatre's current schedule. This violates C-5 and R-36 if presented as a real-time confirmation.

   Proposed fix: show the post date/source in the admin review step, keep the public copy neutral, and retain the theatre's phone confirmation path until a valid Page access token is configured.

## Approval gate

No public listing, KV record, GitHub commit, or deployment was changed by this audit. Approve the specific finding numbers before implementation, for example: `Approve 1 and 2; use Screen 2 for Heart of the Beast.`
